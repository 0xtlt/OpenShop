title: How-to guides
description: Task-focused instructions for building, testing, deploying, and operating an existing OpenShop app.
---

These guides assume you already have an OpenShop project. If you are starting
from an empty directory, follow the [first-app tutorial](/tutorials/first-app/).
Run app commands from the directory containing `openshop.config.ts`.

## Build an integration

| I want to… | Guide |
| --- | --- |
| Configure one or several Shopify apps | [Configure Shopify apps](/guides/configure-shopify-apps/) |
| Save credentials and call an external API | [Connect an external service](/guides/define-provider/) |
| Send Shopify orders to a provider on a schedule | [Sync orders with a flow](/guides/define-flow/) |
| Respond to Shopify events | [Handle a Shopify webhook](/guides/handle-webhooks/) |
